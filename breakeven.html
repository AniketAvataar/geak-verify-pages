Kernel reuse across tasks

Reuse

Same base model + same LoRA setup (rank, target modules, dtype, similar batch/seq) → same kernels. Medical coding and influencer marketing on Qwen3-32B share one GEAK generation; only the dataset changes.

New GEAK

Need fresh kernels if you change architecture, LoRA rank/targets, precision, or shapes enough that tiling/autotune no longer fits. Task label alone does not force a redo.

So break-even is really “how many fine-tunes on this stack,” not “how many business tasks.”

Claude margins

Scales generation cost only. Lower if Opus needs fewer agent steps than Gemma.

0% = measured GEAK with compile fallback. Higher = assume Claude GEAK gets faster (still never slower than compile per op).
