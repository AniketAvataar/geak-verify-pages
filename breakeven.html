When can you reuse the same kernels?

Likely reusable

If two fine-tunes use the same base model and the same LoRA setup (rank, which layers get LoRA, precision, and roughly similar batch/sequence sizes), the training step is doing the same kinds of math.

So a medical-coding run and an influencer-marketing run on Qwen3-32B can probably share one set of GEAK kernels. You are not paying GEAK again just because the dataset changed. We have not proven this for every stack — it is the usual expectation for operator-level kernels.

Likely need a new GEAK pass

If you change the model family, LoRA rank, which modules are adapted, precision (for example bf16 vs fp8), or move to very different sequence lengths, the shapes change and the old kernels may no longer be a good fit.

In short: break-even is closer to “how many fine-tunes on this model+LoRA stack,” not “how many business use-cases.”
